# 🛠️ Lab 04. 커스텀 패킷 프레이밍 & CRC 검증 (Custom Packet Framing)

실제 임베디드 시리얼 통신(UART, RS-485, 무선) 환경에서는 노이즈, 패킷 깨짐, 바이트 유실이 발생할 수 있습니다. 이를 극복하기 위해 **시작 바이트(STX)**, **길이(Length)**, **명령어(Command)**, **데이터(Payload)**, **CRC16 체크섬**, **종료 바이트(ETX)** 로 구성된 산업 표준 패킷 프레이밍 엔진을 구현합니다.

---

## 📌 패킷 구조 규격

```text
┌───────┬──────────┬──────────┬──────────┬──────────────┬─────────────┬───────┐
│  STX  │ Length   │  SeqNum  │  Cmd ID  │   Payload    │    CRC16    │  ETX  │
│ (0x02)│ (2 Byte) │ (1 Byte) │ (1 Byte) │  (N Bytes)   │  (2 Bytes)  │ (0x03)│
└───────┴──────────┴──────────┴──────────┴──────────────┴─────────────┴───────┘
```

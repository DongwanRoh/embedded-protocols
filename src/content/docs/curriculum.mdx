## 🟢 Phase 1: 기초 통신 (4~6주)

### Week 1~2: 디지털 입출력 & 시리얼 기초 이론

**이론 체크리스트:**
- MCU 아키텍처 기초 (CPU, 클록 트리, GPIO 레지스터, AHB/APB 버스)
- 디지털 출력(Push-Pull, Open-Drain), 디지털 입력(Pull-up/Pull-down/Floating)
- 시리얼 vs 패러럴, 동기 vs 비동기, 전이중 vs 반이중
- TTL / RS-232 / RS-485 전압 레벨 비교

**실습 과제:**

| # | 실습 내용 | 난이도 | 장비 |
| :---: | :--- | :---: | :--- |
| 1-1 | LED Blink (GPIO 출력) | ⭐ | Nucleo 내장 LED |
| 1-2 | 버튼 + LED (GPIO 입력 + 디바운싱) | ⭐ | 택트 스위치 + LED |
| 1-3 | 외부 인터럽트(EXTI) 버튼 감지 | ⭐⭐ | 택트 스위치 |

### Week 3~4: UART 통신 마스터

**이론 체크리스트:**
- UART 프레임 포맷 (Start, Data 7/8bit, Parity N/E/O, Stop 1/2bit)
- 보드레이트 계산, 오버샘플링 16x/8x
- RTS/CTS 하드웨어 흐름 제어
- 수신 아키텍처: Polling → Interrupt+링버퍼 → DMA+IDLE Line

**실습 과제:**

| # | 실습 내용 | 난이도 | 장비 |
| :---: | :--- | :---: | :--- |
| 1-4 | UART 에코 서버 (Polling 방식) | ⭐ | Nucleo + USB-UART + PuTTY |
| 1-5 | printf → UART 리다이렉션 | ⭐⭐ | Nucleo + USB-UART |
| 1-6 | 인터럽트 + 링버퍼(Ring Buffer) 수신 | ⭐⭐⭐ | Nucleo + USB-UART |
| 1-7 | DMA + IDLE Line 가변 길이 수신 | ⭐⭐⭐ | Nucleo + USB-UART |

### Week 5~6: PWM & 타이머

**실습 과제:**

| # | 실습 내용 | 난이도 | 장비 |
| :---: | :--- | :---: | :--- |
| 1-8 | LED 밝기 PWM 제어 (페이드 인/아웃) | ⭐ | Nucleo 내장 LED |
| 1-9 | 서보모터 50Hz PWM 각도 제어 | ⭐⭐ | SG90 서보모터 |

# 📚 01. 시리얼 통신 기초 (Serial Communication Fundamentals)

## 📌 1. 패러럴(Parallel) vs 시리얼(Serial) 통신
- **패러럴 통신**: 여러 데이터 선(Data Bus)을 통해 한 번에 다수의 비트(8, 16, 32bit 등)를 동시에 전송
  - *단점*: 선로 간 신호 왜곡(Skew), 누화(Crosstalk), 핀 수 증가로 고속/장거리 전송에 불리
- **시리얼 통신**: 단일 데이터 선(또는 차동 2선)을 통해 시간 순서대로 1비트씩 직렬 전송
  - *장점*: 적은 핀 수, 높은 노이즈 내성, 고속화 용이 (오늘날 대부분의 고속 인터페이스가 시리얼 채택)

---

## 📌 2. 통신 방식 분류
1. **데이터 전송 방향**:
   - **단방향 (Simplex)**: 한쪽 방향으로만 송신 (예: 라디오 수신, GPS 모듈 출력)
   - **반이중 (Half-Duplex)**: 양방향 통신이 가능하나, 동시에 불가 (예: 무전기, I2C, RS-485)
   - **전이중 (Full-Duplex)**: 송신과 수신을 동시에 진행 (예: 전화기, UART, SPI)

2. **클록 동기화 방식**:
   - **동기식 (Synchronous)**: 송수신기가 **클록(Clock, SCK)** 라인을 공유하여 클록 에지에 맞춰 비트를 샘플링 (예: I2C, SPI, I2S)
   - **비동기식 (Asynchronous)**: 별도 클록 라인이 없으며, 사전에 약속된 **통신 속도(Baud Rate)** 와 시작/정지 비트로 타이밍을 동기화 (예: UART, CAN)

---

## 📌 3. 물리 계층 전기적 신호 규격
- **TTL (Transistor-Transistor Logic)**: 0V (GND, Logic 0) ~ 3.3V 또는 5V (VCC, Logic 1). MCU 핀 레벨.
- **RS-232**: +3V ~ +15V (Logic 0 / Space), -3V ~ -15V (Logic 1 / Mark). 노이즈 내성을 높여 수~수십 미터 전송.
- **RS-485 / RS-422**: 차동 신호(A-B 선간 전압차)를 사용하여 최대 1.2km 장거리 및 1:N 멀티드롭 통신 지원.
